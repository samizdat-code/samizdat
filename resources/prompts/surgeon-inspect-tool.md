{% if usage %}inspect_clojure({requests, expect}) reads exact Clojure structure from frozen workspace snapshots. Each request names a project-relative .clj, .cljs, or .cljc file and one operation: outline {operation, file}; forms {operation, file, form|forms|line|contains, platform?, include-source?}; match {operation, file, match, inside?}; xray {operation, file, expression, evidence?}, where expression is one pure Clojure path such as (-> (form 'name) (match :key) right (expect-count 1) (analyze pure-function)). X-ray paths support form/line roots, structural match/where, right/left/up/down/outermost navigation, initializer, span, and partition-all; analysis receives a stable vector of parsed syntax as data, never evaluated program state, and must return realized EDN. evidence is "compact" (source hashes) by default or "full" (exact source). X-ray never writes and cannot perform I/O, load namespaces, mutate host state, or use classes/interop. expect must give the exact total request and distinct-file counts: {requests: n, files: n}. Results preserve request order and carry SHA-256 revisions.
