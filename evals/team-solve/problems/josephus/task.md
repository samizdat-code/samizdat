N people stand in a circle, numbered 1..N. Counting starts at person 1; every
K-th person leaves the circle until one remains. Print the number of the last
person standing.

## Input
One line: N and K (1 <= N <= 10^6, 1 <= K <= 10^6).

## Output
One integer.

## Examples
- N=5 K=2 -> `3`
- N=1 K=99 -> `1`
