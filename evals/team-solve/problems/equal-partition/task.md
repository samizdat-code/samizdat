Can the given list of positive integers be split into two parts with equal
sums? Print YES or NO. Every element must be in exactly one part.

## Input
Two lines: N, then the N integers.

## Output
YES or NO.

## Constraints
1 <= N <= 400, 1 <= a[i] <= 500.

## Examples
- `1 5 11 5` -> YES (1+5+5 = 11)
